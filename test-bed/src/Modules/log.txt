#5 46.78 Packages
#5 46.78 ========
#5 46.78 
#5 46.78 The packages provided here are loosely based on the debian upstream packages with some modifications to make them more usable as non-default pythons and on ubuntu.  As such, the packages follow debian's patterns and often do not include a full python distribution with just `apt install python#.#`.  Here is a list of packages that may be useful along with the default install:
#5 46.78 
#5 46.78 - `python#.#-dev`: includes development headers for building C extensions
#5 46.78 - `python#.#-venv`: provides the standard library `venv` module
#5 46.78 - `python#.#-distutils`: provides the standard library `distutils` module
#5 46.78 - `python#.#-lib2to3`: provides the `2to3-#.#` utility as well as the standard library `lib2to3` module
#5 46.78 - `python#.#-gdbm`: provides the standard library `dbm.gnu` module
#5 46.78 - `python#.#-tk`: provides the standard library `tkinter` module

#5 46.78 Third-Party Python Modules
#5 46.78 ==========================
#5 46.78 
#5 46.78 Python modules in the official Ubuntu repositories are packaged to work with the Python interpreters from the official repositories. Accordingly, they generally won't work with the Python interpreters from this PPA. As an exception, pure-Python modules for Python 3 will work, but any compiled extension modules won't.
