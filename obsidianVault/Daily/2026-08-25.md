# 2026-08-25

## Built AP radar charts (sed/bus × low/medium/high severity) for ASF robustness eval

New module [[robustness-radar-charts]] — `test-bed/src/Modules/robust_testing/kradar/scripts/analysis/radar_charts.py`.
Audited existing plotting/AP infrastructure first (`ap_metrics.py`'s `compute_ap_grouped`,
`build_figures.py`'s pooled-mAP figures) and reused rather than reimplementing. Produces 6
radar/spider charts per run — one per (class ∈ {sed, bus}) × (severity ∈ {low, medium, high}) —
either for a single K-Radar sequence (`--sequence 46`) or pooled across all 58
(`--sequence all`). 10 axes per chart: `OG`=clean baseline (bold star) + 9 sensor×effect
severity-tiered conditions (two-letter codes, e.g. `RF`=radar frame-deletion).

Two data-quality bugs surfaced and fixed along the way, both about AP getting computed
silently on bad/incomplete data without any visual flag:

- Sequence 46 is missing 3 conditions entirely (0 rows) — now drawn as an explicit `(N/A)`
  gap in the chart, never zero-filled.
- Several `frame_deletion` conditions have near-zero frame coverage (as low as 1 frame) from
  the same class of mid-run Alvis disk-quota crash documented in
  [[asf-corruption-study-alvis]] — now flagged with an orange `x` marker, coverage %, and a
  footnote, excluded from the connecting line, instead of being plotted as an ordinary data
  point indistinguishable from a fully-covered condition.

Output: PNG+SVG in `test-bed/src/Modules/robust_testing/kradar/output/radar_charts/`.
